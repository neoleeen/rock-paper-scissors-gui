# Rock Paper Scissors GUI

A simple Rock Paper Scissors game with a graphical interface, built while completing the **GitHub Copilot course on [Codédex]([https://www.codedex.io](https://www.codedex.io/github-copilot))**

## About this project

The goal of this project wasn’t really the game, it was learning how to work alongside an AI coding assistant. I mostly vibe coded it, describing what I wanted, letting GitHub Copilot generate the code, then reviewing, testing and adjusting the results. Along the way I also picked up the basics of Tkinter for building the GUI, and got a real feel for how AI can complement the coding process.
